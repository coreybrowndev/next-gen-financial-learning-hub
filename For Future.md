# Known Issues and Improvements

This document outlines current known issues within the Intertwined CMS project and suggests future improvements for upcoming development teams.

---

## Known Issues

### 1. **Breadcrumb Links**
- **Issue**: The breadcrumbs link which have numbers attached will not route to a valid page .
- **Workaround**: The UI will provide you with an error to navigate back to where you came.
- **Priority**: High

### 2. **Slow load times when uploading course content**
- **Issue**: Courses with large amounts of data will take 5+ minutes to import and suffers from slow load time.
- **Root Cause**: Perfomance issue with implememtation.
- **Priority**: Medium

### 3. **Mobile Responsiveness Gaps**
- **Issue**: Some UI components (e.g., dropdowns, modals) are not fully responsive on mobile devices.
- **Priority**: Low

---
